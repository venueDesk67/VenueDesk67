# VenueDesk website

A responsive, static website ready for GitHub Pages. It uses plain HTML, CSS and JavaScript. No paid hosting, build tools or frameworks are required.

## Before publishing

1. Open `config.js`.
2. Replace `YOUR_EMAIL_ADDRESS` with the exact business email address you want customers to use.
3. Save the file.
4. Preview `index.html` in a browser if possible.

Do not publish until the contact email is correct.

## Publish free with GitHub Pages

1. Sign in to GitHub or create a free account at https://github.com/.
2. Select **New repository**.
3. Name it `venuedesk-website`.
4. Set it to **Public** and create the repository.
5. Choose **Add file → Upload files**.
6. Upload `index.html`, `styles.css`, `config.js`, `script.js` and this `README.md` (upload the files themselves, not the ZIP).
7. Select **Commit changes**.
8. Open the repository's **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch **main**, folder **/(root)**, then **Save**.
11. Wait a few minutes. GitHub will show the published address, normally:
   `https://YOUR-GITHUB-USERNAME.github.io/venuedesk-website/`

## Important

- This is a static information website. It does not yet accept or store form submissions.
- The email button opens the visitor's email app using the address in `config.js`.
- The website is not published until you complete the GitHub Pages steps.
- A custom domain such as `venuedesk.co.uk` is optional and requires domain registration. Do not configure one unless you own it.
- The site describes staff approval for booking decisions. It does not claim to provide live availability or automatic booking confirmation.

## Updating the site

Edit the relevant file in the GitHub repository and commit the change. GitHub Pages republishes the site automatically.
